BusControl PRO 5.0 — крупное обновление

Добавлено/изменено:
- Финансовая модель: Автобус / Кредиты / Заначка — реальные остатки; Личные — статистика заработанного себе.
- Свободные переводы с личными как внешним источником; личные рабочие расходы и расходы из заначки создают обязательство возврата/восстановления.
- Выплата предприятия: распределение в процентах или рублях.
- Оплаты заказов: добавлена Заначка в распределение.
- Платежи кредитов с указанием месяца (поддержка уже встроена в базу 4.2/13).
- Центр 5.0: подробная история по месяцам, сравнение с предыдущим месяцем, годовые итоги, поиск по истории, долги заказов, планируемые расходы.
- Расход топлива автобуса на 100 км в месячной сводке.
- Личный автомобиль: отдельный тип транспорта и журнал запчастей/ремонтов/ТО без топлива и рабочей бухгалтерии.
- ТО/обслуживание: индивидуальные сроки по дате/пробегу и два интервала напоминаний.
- Локальные iOS/Android уведомления заказов: за день и второй интервал (reminderHours), пересоздаются при редактировании и отменяются при удалении/закрытии.
- Быстрые действия и блок «Требует внимания» на Сегодня.
- Excel/PDF: имя «Сводка_Месяц_Год», без текста при отправке; Excel содержит явные счётчики утро/вечер/утро+вечер/доп. рейсы.
- Backup включает новые таблицы; перед восстановлением создаются до 3 защитных локальных снимков.
- БД: версия 14 с миграцией старых данных.

После распаковки:
flutter pub get
flutter analyze

Важно: проект подготовлен без локального Flutter SDK в среде сборки ChatGPT, поэтому финальный flutter analyze нужно выполнить на вашем ПК.
