# BusControl PRO 4.0 Alpha 1 — Cloud Auth

## Что уже работает

- регистрация по почте и паролю;
- вход и сохранение сессии;
- восстановление пароля;
- профиль пользователя;
- выход из аккаунта;
- разделение пользователей через Supabase Auth;
- существующие рабочие данные пока остаются в локальной SQLite/IndexedDB.

## Перед запуском

В Supabase SQL Editor один раз выполните:

`supabase/migrations/20260806_0002_client_grants.sql`

## Запуск Web

```powershell
flutter clean
flutter pub get
flutter analyze
flutter run -d chrome --web-port 8080
```

## Запуск Android

```powershell
flutter run -d emulator-5554
```

## Проверка

1. Создайте новый аккаунт.
2. Убедитесь, что после регистрации открывается приложение.
3. Перезапустите приложение — сессия должна сохраниться.
4. Откройте «Ещё» → «Облачный профиль».
5. Измените имя и сохраните.
6. Выйдите и войдите снова.

## Безопасность

В клиенте используется только publishable key. Service role key и пароль базы в проект добавлять нельзя.
