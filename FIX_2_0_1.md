# Исправление зависимостей — версия 2.0.1

Перед запуском обязательно выполните из корня проекта:

```bash
flutter clean
flutter pub get
flutter analyze
flutter run -d emulator-5554
```

Исправлено:
- добавлены совместимые зависимости Flutter;
- удалён старый pubspec.lock;
- удалено дублирование getDatabaseFilePath();
- API share_plus приведён к совместимой версии;
- исправлен цвет заголовков Excel;
- удалён неиспользуемый импорт.

Если VS Code продолжает показывать старые ошибки после `flutter pub get`,
выполните команду `Dart: Restart Analysis Server` через Ctrl+Shift+P.
