# BusControl PRO 3.0.2

Исправлено:

- карточки «Рейсы», «Заказы», «Топливо» и «Пробег» во вкладке «Автобус» стали кликабельными;
- рейсы, заказы и топливо открывают историю текущего месяца;
- пробег открывает отдельную историю завершённых дней;
- форма добавления и редактирования кредита теперь сама управляет контроллерами;
- закрытие формы кредита больше не освобождает контроллеры до удаления диалога;
- аналогично исправлено окно ручного платежа по кредиту;
- добавлена проверка сумм, процентов и дня платежа;
- ошибки сохранения показываются сообщением вместо аварийного завершения.

Проверка:

1. Открыть «Автобус».
2. Нажать по каждой из четырёх карточек статистики.
3. Открыть «Финансы → Кредиты».
4. Несколько раз открыть и закрыть «Новый кредит».
5. Создать кредит, отредактировать его и добавить платёж.
