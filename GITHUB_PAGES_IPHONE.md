# BusControl PRO 3.3 PWA — GitHub Pages

Эта версия предназначена для постоянного использования на iPhone без IPA,
Mac, сертификатов и переподписи.

## Что адаптировано для браузера

- SQLite работает через `sqflite_common_ffi_web` и хранится в IndexedDB.
- Резервная копия скачивается браузером как `.buscontrol`.
- Восстановление выполняется через системный выбор файла.
- PDF и Excel скачиваются как обычные файлы.
- Интерфейс работает в standalone-режиме с Safe Area для iPhone.
- Добавлена автоматическая сборка и публикация через GitHub Actions.
- После первой загрузки Flutter Web-кэш позволяет открывать приложение без сети.
- Все таблицы: транспорт, кредиты, рейсы, заказы, оплаты, топливо, расходы,
  пробег, ТО и настройки входят в резервную копию.

## Публикация на GitHub

1. Создай новый публичный репозиторий, например `buscontrol-pro`.
2. Загрузи в него **содержимое папки проекта**, чтобы `pubspec.yaml`
   находился в корне репозитория.
3. В GitHub открой `Settings → Pages`.
4. В `Build and deployment → Source` выбери `GitHub Actions`.
5. Открой вкладку `Actions`.
6. Дождись завершения процесса `Deploy BusControl PRO PWA`.
7. Ссылка появится в `Settings → Pages` и в результате шага Deploy.

Обычно адрес выглядит так:

`https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/buscontrol-pro/`

## Установка на iPhone

1. Открой полученную ссылку именно в Safari.
2. Нажми кнопку «Поделиться».
3. Выбери «На экран Домой».
4. Включи «Открывать как веб-приложение», если iOS показывает этот пункт.
5. Нажми «Добавить».

## Важное о данных

Данные хранятся локально на конкретном iPhone в хранилище сайта.
Не очищай данные Safari для адреса GitHub Pages и не удаляй веб-приложение
до создания резервной копии.

Рекомендуется:
- создавать `.buscontrol` после важных изменений;
- хранить копии в iCloud Drive или «Файлах»;
- перед обновлением крупной версии создавать резервную копию.

## Обновления

После загрузки новой версии в ветку `main` GitHub автоматически:
- проверит проект;
- соберёт Flutter Web;
- опубликует новую версию.

На iPhone новая версия обычно подхватывается после полного закрытия и
повторного открытия приложения. Старые данные остаются в IndexedDB,
пока адрес сайта и имя базы не меняются.
