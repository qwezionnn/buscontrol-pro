BusControl PRO 4.1 — обычные рейсы из календаря

Добавлено:
- Утренний рейс на любую дату.
- Вечерний рейс на любую дату.
- Дополнительный рейс оставлен как раньше.
- Утренний/вечерний создаются невыполненными.
- Нажмите на созданный рейс в календаре, чтобы отметить его выполненным.
- Если такой обычный рейс уже есть на этой дате, дубль не создаётся.
- Добавление утреннего рейса НЕ создаёт автоматически вечерний и наоборот.
- Километраж в дополнительный рейс не добавлялся.

Установка:
распаковать поверх C:\Projects\bus_control_pro_final с заменой файлов.

Проверка:
flutter analyze
flutter run -d web-server --web-port 5050
