BusControl PRO — исправление backup / sync

Исправлено:
1. После восстановления локальной резервной копии HomeScreen получает событие и
   полностью пересоздаёт Сегодня, Календарь, Финансы, Автобус и Настройки.
2. Критическая ошибка первого входа на втором устройстве:
   раньше при lastHash == null локальная свежая база считалась изменённой и могла
   перезаписать уже существующий облачный snapshot.
   Теперь если облачная копия уже существует, при первом sync новое устройство
   сначала СКАЧИВАЕТ облачную копию.
3. После cloud import revision обновляется, HomeScreen перечитывает вкладки.
4. database_version в cloud snapshot исправлен с 9 на 10.

Установка:
распаковать поверх C:\Projects\bus_control_pro_final

Проверка:
flutter analyze

Тест двух телефонов:
- На основном телефоне выполнить облачную синхронизацию.
- На втором телефоне войти в тот же аккаунт.
- Дождаться синхронизации.
- Проверить Календарь и Автобус.
- Для ручного .buscontrol backup: восстановить файл и сразу проверить вкладки,
  без перезапуска приложения.
