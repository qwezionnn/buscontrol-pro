BusControl PRO 4.1 — расходы автобуса

Добавлено:
- Вкладка «Автобус» -> новый раздел «Расходы».
- На карточке показывается сумма расходов за текущий месяц.
- Внутри раздела можно листать месяцы назад/вперёд.
- Видно: дата, время, категория, описание и сумма каждой покупки/ремонта.
- Поддерживаются существующие категории: ремонт, запчасти, мойка,
  страховка, парковка, штраф, прочее.
- Нажатие на расход -> Редактировать / Удалить.
- При редактировании можно изменить дату, время, категорию, сумму и описание.
- Кнопка + позволяет добавить новый расход прямо из раздела автобуса.

Важно:
Расходы берутся из той же таблицы expenses, поэтому записи, которые уже
добавлялись через «Сегодня» или календарь, автоматически появятся здесь.

Установка:
Распаковать архив поверх:
C:\Projects\bus_control_pro_final

с заменой файлов.

Проверка:
flutter analyze

Если нет ERROR:
flutter run -d web-server --web-port 5050

Проверить:
1. Автобус -> Расходы.
2. Открыть старый расход.
3. Изменить сумму/описание/дату.
4. Сохранить и убедиться, что изменения видны также в календаре/финансах.
