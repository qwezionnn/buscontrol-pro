BusControl PRO 4.1 — удаление записей из календаря

Добавлено:
- Заказ: меню Редактировать / Выполнить / Добавить оплату / Удалить.
  При удалении заказа удаляются и связанные оплаты.
- Заправка: нажатие на запись → Удалить заправку.
- Расход: нажатие на запись → Удалить расход.
- Дополнительный рейс: нажатие → отметить выполненным/не выполненным или удалить.
- Утренний и вечерний рейсы не удаляются, потому что приложение считает их системными
  и автоматически создаёт заново. Их можно отметить выполненными/не выполненными.
- Перед каждым удалением есть подтверждение.

Как установить:
1. Распаковать архив поверх C:\Projects\bus_control_pro_final с заменой файлов.
2. Выполнить:
   flutter analyze
3. Запустить и проверить календарь.
4. Если всё хорошо:
   git add .
   git commit -m "Add calendar delete actions"
   git push origin main
