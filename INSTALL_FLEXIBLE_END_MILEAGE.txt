BusControl PRO 4.1 — конечный пробег в любое время + выбор даты

Что изменено:
- Конечный пробег больше не привязан к какому-либо времени суток.
- Его можно внести утром, днём или вечером — как только работа за день закончилась.
- Добавлен выбор даты.
- Можно выбрать сегодняшний или любой прошлый день.
- Будущую дату выбрать нельзя, потому что конечный пробег будущего дня ещё неизвестен.
- Пример: 11.08.2026 -> конечный пробег 358612 км.
- Если пробег за выбранную дату уже сохранён, можно нажать
  «Исправить конечный пробег» и сохранить новое значение.
- При внесении задним числом приложение берёт начало дня из ближайшего
  предыдущего завершённого дня.
- При исправлении старого дня приложение не откатывает текущий пробег автобуса назад.

Установка:
Распаковать архив поверх:
C:\Projects\bus_control_pro_final

с заменой файлов.

Проверка:
flutter analyze

После этого:
flutter run -d web-server --web-port 5050

Проверить:
1. Сегодня -> выбрать сегодняшнюю дату -> внести конечный пробег.
2. Выбрать вчерашнюю дату -> внести пробег задним числом.
3. Открыть уже заполненную дату -> «Исправить конечный пробег».
4. Проверить историю пробега во вкладке Автобус.
