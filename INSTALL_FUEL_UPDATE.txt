BusControl PRO 4.1 — домашняя заправка + АЗС

Что добавлено

1. При добавлении топлива теперь выбирается:
   - На АЗС
   - Дома

2. На АЗС доступны два способа:
   А) Литры + цена за литр -> сумма считается автоматически.
   Б) Сумма + цена за литр -> количество литров считается автоматически.

3. Заправка дома:
   - указывается только количество литров;
   - цена за литр не нужна;
   - деньги при каждой домашней заправке НЕ списываются;
   - литры сразу учитываются в истории и статистике топлива.

4. Расчёт домашнего топлива:
   - во вкладке топлива появилась кнопка «Расчёт домашнего топлива»;
   - выбирается месяц;
   - приложение показывает, сколько литров за этот месяц было заправлено дома;
   - вводится одна ФАКТИЧЕСКАЯ общая сумма;
   - выбирается дата списания;
   - сумма списывается с кошелька автобуса как расход на топливо.

5. Финансы и отчёты:
   - домашняя заправка до расчёта не создаёт денежный расход;
   - месячная фактическая сумма домашнего топлива относится к расходам на топливо;
   - эта сумма уменьшает доступный кошелёк автобуса;
   - обычные расходы при этом не задваиваются.

6. База:
   - версия БД: 10;
   - существующим старым заправкам автоматически присваивается тип station (АЗС);
   - данные не удаляются.

7. Календарь:
   - домашняя заправка отображается как «Заправка дома» и «без списания»;
   - АЗС отображается отдельно.

Установка

Распаковать архив поверх:
C:\Projects\bus_control_pro_final

с заменой файлов.

Проверка

cd C:\Projects\bus_control_pro_final
flutter clean
flutter pub get
flutter analyze

Если нет ERROR:
flutter run -d web-server --web-port 5050

Проверить:
1. Топливо -> На АЗС -> Литры + цена.
2. Топливо -> На АЗС -> Сумма + цена.
3. Топливо -> Дома -> указать только литры.
4. Создать несколько домашних заправок.
5. «Расчёт домашнего топлива» -> выбрать месяц -> ввести общую фактическую сумму.
6. Проверить, что сумма уменьшила кошелёк автобуса.
