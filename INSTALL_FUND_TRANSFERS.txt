BusControl PRO 4.1 — переводы между счетами

Добавлено:
- Переводы Автобус ↔ Кредиты ↔ Личные.
- Можно выбрать любой исходный и целевой счёт.
- Нельзя перевести больше текущего доступного остатка.
- Перевод не является доходом или расходом: он только перемещает деньги между счетами.
- История переводов хранится в базе.
- Долгое нажатие на запись истории позволяет удалить ошибочный перевод.
- В Финансах отображаются текущие остатки всех трёх счетов.

Важно:
- Перевод с «Кредиты» НЕ уменьшает задолженность банку. Это только перемещение денег,
  которые были отложены в кредитный фонд.
- Для реального погашения кредита остаётся существующая функция оплаты кредита.

Backup / Cloud:
- fund_transfers добавлена в резервную копию и облачный snapshot.
- Версия БД повышена до 11.
- В этот пакет также включено предыдущее исправление первого sync второго телефона:
  существующее облако сначала скачивается, а не перезаписывается пустой локальной базой.
- После ручного восстановления backup вкладки приложения обновляются.

Установка:
Распаковать поверх:
C:\Projects\bus_control_pro_final

Проверка:
flutter clean
flutter pub get
flutter analyze

Если нет ERROR:
flutter run -d web-server --web-port 5050

Проверить:
1. Финансы → Перевод между счетами.
2. Автобус → Личные.
3. Личные → Кредиты.
4. Кредиты → Автобус.
5. Проверить, что итоговая сумма денег по трём счетам от перевода не меняется.
