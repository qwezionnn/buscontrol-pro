BusControl PRO 4.1 — управление пробегом

Добавлено:
1. Удаление суточного пробега на любой дате.
   Календарь -> выбрать день -> «Пробег за день» -> удалить.
   Удаляется только пробег выбранного дня; рейсы, заказы, топливо и расходы остаются.

2. Пробег отображается прямо в ячейке календаря.
   Например:
   11
   [значки событий]
   146 км

   При открытии дня отображается:
   «146 км за день • конечный 358612 км».

3. Настройки -> Опасная зона -> «Сбросить только пробег».
   Сбрасывает:
   - всю историю суточного пробега активного автобуса;
   - начальный пробег;
   - текущий пробег.
   НЕ удаляет:
   - рейсы;
   - заказы;
   - топливо;
   - расходы;
   - кредиты;
   - финансы и остальные настройки.

4. После удаления отдельного дня текущий одометр автоматически
   пересчитывается по последнему оставшемуся завершённому дню.

Установка:
Распаковать поверх:
C:\Projects\bus_control_pro_final

с заменой файлов.

Проверка:
flutter analyze

Если нет ERROR:
flutter run -d web-server --web-port 5050

Проверить:
- внести пробег на несколько дат;
- открыть календарь и увидеть км прямо в датах;
- удалить пробег одной даты;
- убедиться, что остальные события даты остались;
- Настройки -> Сбросить только пробег;
- убедиться, что рейсы/заказы/финансы не исчезли.
