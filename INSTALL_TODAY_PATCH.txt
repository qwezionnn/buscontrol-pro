BusControl PRO — патч сегодняшних изменений

Распаковать содержимое архива в корень проекта C:\Projects\bus_control_pro_final с заменой файлов.
После замены выполнить:
  flutter pub get
  flutter analyze

В патче:
- ручная корректировка заначки;
- источник оплаты кредита: Кредит / Автобус / Заначка / Наличные-личные;
- вкладка Рейсы в месячной истории: утро, вечер, полные/неполные дни, доп. рейсы, суммы;
- доп. рейс: собственное название, часы ожидания и индивидуальная ставка ожидания; ожидание не считается рейсом;
- личный автомобиль без коммерческой статистики, как журнал ТО/ремонтов/запчастей;
- экспорт PDF/Excel с выбором галочками разделов;
- экспорт отправляет только файл без сопроводительного текста.
