BusControl PRO — Widget toggle idempotency fix

Fixes the issue where tapping Morning/Evening briefly checked the item and then immediately unchecked it in both the widget and app.

Cause: the interactive intent could be executed more than once; the old implementation treated each execution as a toggle.
Fix: the widget now sends an explicit target state derived from the rendered state. Repeated executions write the same target value, so they cannot toggle back.

Files:
- ios/Shared/BusControlWidgetIntent.swift
- ios/BusControlLiveActivity/BusControlLiveActivity.swift
- ios/Runner/AppDelegate.swift
