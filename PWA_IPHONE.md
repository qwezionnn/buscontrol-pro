# BusControl PRO 3.2 PWA

Эта версия предназначена для установки на iPhone без IPA, Mac и сертификатов.

## Что изменено

- SQLite работает в браузере через WebAssembly и хранится в IndexedDB.
- Основные данные доступны офлайн после первого запуска.
- Резервная копия теперь является переносимым JSON-файлом `.buscontrol`.
- Одна и та же копия подходит для Web/PWA и мобильной версии 3.2+.
- Добавлены название, иконки, фирменная заставка и режим standalone.
- Интерфейс учитывает Safe Area iPhone.

## Первый запуск на Windows

В PowerShell из папки проекта:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\prepare_web.ps1
```

Скрипт:
1. загрузит пакеты;
2. создаст `web/sqlite3.wasm` и `web/sqflite_sw.js`;
3. выполнит анализ;
4. соберёт PWA в `build/web`.

## Проверка в браузере

```powershell
python -m http.server 8080 --directory build/web
```

Открой `http://localhost:8080`.

Для проверки именно на iPhone нужен HTTPS-хостинг. Локальный HTTP на другом устройстве
не считается безопасным контекстом и может ограничить PWA/Service Worker.

## Бесплатный хостинг

Подойдут GitHub Pages, Cloudflare Pages, Netlify или Firebase Hosting.
Загружать нужно содержимое папки `build/web`.

## Установка на iPhone

1. Открой опубликованную HTTPS-ссылку именно в Safari.
2. Нажми кнопку «Поделиться».
3. Выбери «На экран Домой».
4. Включи «Открывать как веб-приложение», если iOS покажет этот переключатель.
5. Запусти BusControl PRO с домашнего экрана.

## Данные и резервные копии

Данные хранятся локально в браузере iPhone. Не очищай данные Safari для сайта,
не создав резервную копию.

Рекомендуется регулярно:
`Ещё → Резервная копия → Создать резервную копию`.

## Ограничения Preview

- Web SQLite является экспериментальным.
- PDF с кириллицей может впервые потребовать интернет для загрузки шрифта.
- Системные push-уведомления пока не подключены.
- После обновления зависимостей повтори:
  `dart run sqflite_common_ffi_web:setup --force`
