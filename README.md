# BusControl PRO

Личное приложение для учёта рейсов, заказов, топлива, расходов и пробега автобуса.

## Запуск

```bash
flutter pub get
flutter analyze
flutter run -d emulator-5554
```

## Первый запуск

1. Откройте вкладку «Ещё».
2. Укажите начальный пробег автобуса.
3. Настройте стоимость стандартного рейса, ставки заказов, топливо и проценты фондов.
4. Вернитесь на вкладку «Сегодня».

## Основные разделы

- **Сегодня** — текущие рейсы, заказы, заправки, расходы и конечный пробег.
- **Календарь** — история событий по дням.
- **Финансы** — месячная прибыль, расходы и распределение денег.
- **Автобус** — текущий пробег и технические параметры.
- **Ещё** — редактируемые настройки.

## Примечание

Локальные push-уведомления пока не включены в сборку: для них потребуется
добавить Android-разрешения и проверить поведение на реальном устройстве.
Все данные приложения хранятся локально в SQLite.

## Отчёты

Во вкладке «Финансы» выберите месяц и используйте:

- «Рейсы» — история выполненных стандартных и дополнительных рейсов.
- «Заказы» — история заказов с датой, временем, объёмом, суммой и статусом.
- «Топливо» — история заправок с литрами, ценой, суммой, пробегом и комментарием.
- «Экспорт PDF» — готовый месячный отчёт для отправки или сохранения.
- «Экспорт Excel» — книга с листами «Сводка», «Рейсы», «Заказы», «Топливо», «Расходы» и «Пробег».
- «Печать PDF» — системное окно печати Android/iOS.
