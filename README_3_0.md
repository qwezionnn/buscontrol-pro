# BusControl PRO 3.0

Версия 3.0 сохраняет текущую логику приложения и добавляет:

- несколько автобусов и других транспортных средств;
- отдельную историю рейсов, заказов, топлива, расходов, пробега и ТО для каждого ТС;
- быстрое переключение активного транспорта;
- несколько кредитов;
- индивидуальный процент распределения для каждого кредита;
- платежи по кредитам и автоматическое уменьшение остатка;
- единый счёт автобуса: топливо, ТО, страховка, ремонт и прочие расходы списываются только с него;
- запись стоимости ТО сразу после выполнения обслуживания;
- распределение только фактически полученных денег;
- рейсы остаются начисленными до подтверждения месячной выплаты;
- существующие частичные оплаты, отчёты, экспорт и резервные копии.

Текущая рабочая версия `file_picker` зафиксирована: `10.3.10`.
