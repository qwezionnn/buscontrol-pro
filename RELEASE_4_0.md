# BusControl PRO 4.0

Исправления релиза:

1. Стандартные рейсы больше не дублируются при добавлении или переключении автобусов.
2. Уже существующие дубликаты утреннего и вечернего рейса удаляются автоматически при первом запуске обновления.
3. В разделе транспорта добавлена команда «Удалить».
4. В разделе кредитов добавлена команда «Удалить».
5. Удаление требует подтверждения.
6. Удаление автобуса очищает только данные, связанные с ним.
7. Единственный оставшийся автобус удалить нельзя.

Проверка перед использованием:

- открыть приложение после обновления;
- убедиться, что на выбранный день показан один утренний и один вечерний рейс;
- создать второй автобус и переключиться между автобусами;
- удалить тестовый автобус;
- создать и удалить тестовый кредит;
- выполнить облачную синхронизацию.
