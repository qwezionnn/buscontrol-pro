# BusControl PRO 4.0 Release Candidate 1

Это тестовая версия перед 4.0 Stable.

## Что уже работает

- регистрация, вход, восстановление пароля и облачный профиль;
- локальная SQLite/IndexedDB база продолжает обслуживать все экраны;
- вся рабочая база синхронизируется с Supabase как единый снимок аккаунта;
- у каждого пользователя отдельный снимок, защищённый RLS;
- работа без интернета: изменения остаются локально;
- автоматическая проверка синхронизации каждые 45 секунд;
- ручная синхронизация, загрузка локальных данных в облако и восстановление из облака;
- несколько ТС, кредиты, рейсы, заказы, частичные оплаты, топливо, расходы, ТО и настройки входят в снимок;
- PWA-файлы SQLite Web включены в проект.

## Важная модель конфликтов

RC использует local-first и last-writer-wins. Если один и тот же аккаунт одновременно меняет данные
на двух устройствах без синхронизации, при конфликте приоритет получает устройство, которое
последним отправило снимок. Перед переходом на другое устройство нажмите
«Синхронизировать сейчас».

## Перед запуском

В Supabase SQL Editor выполните:

`supabase/migrations/20260806_0003_app_snapshots.sql`

## Проверка

1. Войти в аккаунт.
2. Добавить тестовый автобус, кредит, заказ, оплату, топливо и расход.
3. Открыть «Ещё → Облачный профиль».
4. Нажать «Синхронизировать сейчас».
5. На другом браузере/устройстве войти в тот же аккаунт.
6. Нажать «Восстановить данные из облака».
7. Проверить все записи.
8. Создать другого пользователя: он должен получить отдельную чистую базу.
