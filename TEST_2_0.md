# Проверка BusControl PRO 2.0

1. Выполните заказ на 4 000 ₽.
   - Проверьте предварительное распределение.
   - Во вкладке «Автобус» касса должна получить только долю фонда автобуса.

2. Выполните несколько стандартных рейсов.
   - Во вкладке «Финансы» сумма должна отображаться как начисленная.
   - Касса и распределение не должны включать рейсы до кнопки «Я получил выплату».

3. Нажмите «Я получил выплату».
   - После подтверждения сумма рейсов должна стать доступной для распределения.

4. Добавьте заправку.
   - Сумма должна уменьшить только кассу автобуса.
   - История топлива должна содержать дату, литры, цену, пробег и комментарий.

5. Вкладка «Автобус»:
   - Проверьте статистику.
   - Добавьте ТО по пробегу и по дате.
   - Отметьте обслуживание выполненным.
   - Добавьте экстренный расход.

6. Настройки:
   - Создайте резервную копию.
   - Внесите тестовое изменение.
   - Восстановите резервную копию.
