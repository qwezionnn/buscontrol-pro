# BusControl PRO 2.1 — проверка

## Исправлено
- переполнение ячеек календаря;
- единое зачёркивание выполненных рейсов;
- стабильный полный сброс без пересоздания экрана настроек;
- карточка распределения без выхода за границы экрана.

## Оплата заказов
1. Создайте заказ на 4000 ₽.
2. Нажмите «Выполнен».
3. Выберите:
   - «Оплатят позже», либо
   - введите частичную/полную оплату.
4. Для выполненного заказа отображаются:
   - получено;
   - остаток долга;
   - распределение только фактически полученной суммы.
5. Кнопка «Добавить оплату» позволяет внести остаток позже.
6. «История оплат» показывает каждую оплату отдельно.

Деньги по заказу попадают в кассу и финансового помощника только после фактического получения.
Логика рейсов не изменена: деньги распределяются только после подтверждения месячной выплаты.
