# BusControl PRO 3.0 — проверка

## Перед запуском

```powershell
flutter clean
flutter pub get
flutter analyze
flutter run -d emulator-5554
```

## 1. Несколько автобусов / ТС

1. На верхней панели нажмите кнопку настроек транспорта.
2. Добавьте второй транспорт.
3. Укажите название, госномер и начальный пробег.
4. Переключитесь на него в выпадающем списке сверху.
5. Добавьте рейс, заказ, заправку и расход.
6. Вернитесь на первый транспорт — данные второго не должны отображаться.

Существующие данные автоматически относятся к транспорту «Мой автобус».

## 2. Несколько кредитов

1. Откройте «Финансы» → «Кредиты».
2. Добавьте два кредита, например:
   - Кредит на автобус — 20%;
   - Потребительский кредит — 15%.
3. Выполните заказ и добавьте фактическую оплату.
4. В окне распределения должны отображаться отдельные суммы для каждого кредита.
5. В разделе кредитов запишите платёж — остаток должен уменьшиться.

Проценты применяются только к фактически полученным деньгам. Начисленные,
но ещё не полученные деньги за рейсы не распределяются.

## 3. Счёт автобуса

Счёт автобуса рассчитывается так:

- плюс доля автобуса из фактически полученных оплат заказов;
- плюс доля автобуса после подтверждения месячной выплаты за рейсы;
- минус топливо;
- минус ТО, страховка, ремонт и любые другие расходы транспорта.

При завершении пункта ТО приложение предложит записать стоимость. Эта сумма
попадёт в расходы «ТО и обслуживание» и уменьшит только счёт автобуса.

## 4. Частичная оплата заказа

1. Выполните заказ.
2. Укажите частичную оплату.
3. Убедитесь, что распределяется только полученная сумма.
4. Перезапустите приложение.
5. Добавьте остаток — долг должен стать равен нулю.

## 5. Выплата рейсов

Рейсы начисляются ежедневно, но не поступают в доступные деньги.
Только кнопка «Я получил выплату» во вкладке «Финансы» делает сумму
доступной для распределения.

## 6. Резервная копия

Создайте резервную копию после добавления второго транспорта и кредитов.
После восстановления оба транспорта, кредиты, оплаты и вся история должны
вернуться.
